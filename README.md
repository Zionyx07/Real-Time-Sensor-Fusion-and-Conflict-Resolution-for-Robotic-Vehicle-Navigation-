# Real-Time-Sensor-Fusion-and-Conflict-Resolution-for-Robotic-Vehicle-Navigation-
A deterministic real-time sensor fusion engine for robotic navigation. It resolves conflicting asynchronous telemetry (LiDAR/IR/Ultrasonic) via a 3-tier precedence matrix, supports idempotent event ingestion, versioned state snapshots, timeline replay, and full audit logging.
